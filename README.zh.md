# dsh-find-bar

[English](README.md) | 中文

DSH web 插件：为桌面 App（Electron 壳）补上 **⌘F / Ctrl+F 页内查找**。
v0.5 对齐"零打扰查找"体验：**输入只标记计数、绝不抢走视野**，范围支持
**多选（对话/面板/全部）并可跟随聚焦区**，另补上**区分大小写与全字匹配**。

## 查找与跳转

- **打字 = 只标记**：全文高亮 + 计数实时更新，页面纹丝不动；计数未定位前
  显示总数（如 `17`），定位后变为 `3/17`。
- **按命令才跳转**：Enter / Shift+Enter / ↑↓ 按钮 / ⌘G / F3。
  首次跳转锚定**当前视口**——优先视口内的第一个匹配，否则视口下方最近的
  一个（反向键对称）——绝不会把你拽回文档顶部。
- 目标已完整可见时不滚动；需要滚动时只对最近滚动容器做**最小位移**，
  不再整页连环 scroll。
- 流式输出/折叠展开触发重扫时，当前定位项按锚点（文本节点+偏移）保持，
  不会突然跳到别处。

## 搜索范围（多选 + 聚焦区）

主行右侧 ⋯ 展开**选项行**（默认收起，开合状态记忆）：
`[对话] [面板] [全部]` 三个 chip + `Aa` + `全字` + `⌖ 跟随聚焦区`。

- **多选**：勾两栏＝"全部"；点"全部"＝两栏都勾；最后一栏不允许取消。
  结果按阅读顺序（对话→面板；面板全屏时反过来）排列，Enter 一路顺下去。
- **收起不丢选择**：右栏收起时其 chip 变灰、本次自动跳过该栏，
  **保存的选择原样保留**，展开即恢复。
- **跟随聚焦区**（默认开，⌖ 可关）——打开查找条那一刻：

  | 当时的状态 | 本次范围 | 写回保存值？ |
  |---|---|---|
  | 有选区（起点在某栏） | 仅选区起点所在栏 | ❌ 临时覆盖 |
  | 无选区、保存=全部、最近点击过某栏 | 降级为点击的那栏 | ❌ 临时 |
  | 其他 | 保存值 | ❌ |
  | 手动点 chip | 立即生效 | ✅ 唯一写回途径 |

  判区只认 **pointerdown 点击落点**（不是鼠标悬停）；被临时改写时对应
  chip 闪烁一次作为确认。左栏不纳入范围（dsh 工作区自带搜索）。
- **跳过折叠内容**：被折叠隐藏的文本不参与匹配，展开后约 250ms 自动重计。

## 匹配选项

- **`Aa` 区分大小写**（Alt+C）：`ID` 不再命中 `id`。
- **`全字` 全字匹配**（Alt+W）：`find` 不命中 `finding`/`overflow`；
  中文无空格，CJK 视为天然边界，`字体` 仍然命中 `字体太大`。
- 两个开关都持久化；切换时只重新标记，同样不跳转。

## 原理

- ⌘F/Ctrl+F（capture 阶段）弹出自绘查找条（跟随主题变量）。
- TreeWalker 收集文本节点（含 shadow root），按所选栏限定根
  （`[data-rightbar-col]` 与中央列），`checkVisibility` 过滤折叠内容，
  匹配选项作用于 `findIndices(text, query, {matchCase, wholeWord})`。
- **CSS Custom Highlight API** 高亮——只绘制不改 DOM，与 React 零冲突；
  旧环境退回 `window.find()`，此时选项行整体置灰（无法兑现范围/大小写）。
- MutationObserver 防抖重扫；计数、锚点保持、chip 变灰恢复均自动。

## 快捷键

| 键 | 功能 |
|---|---|
| ⌘F / Ctrl+F | 打开查找条（自动填入当前选中文本） |
| Enter / Shift+Enter | 下一个 / 上一个匹配（首次定位锚定当前视口） |
| ⌘G / F3（+Shift） | 下一个 / 上一个 |
| Alt+C / Alt+W | 区分大小写 / 全字匹配 |
| Esc | 关闭并清除高亮 |

## 安装

```sh
dsh plugin --profile <profile> add dsh-find-bar
```

从 npm 安装（推荐）；或从源码：

```sh
git clone https://github.com/secyborg/dsh-find-bar
dsh plugin --profile <profile> add ./dsh-find-bar
```

安装后重启一次应用（插件清单启动时装载）。

## 已知限制

- 只搜索**已渲染且可见**在 DOM 里的内容；未展开的会话/极长列表若被界面
  折叠，需先展开
- 面板内嵌 iframe 与 shadow DOM 深层内容不在聚焦判区内
- 匹配上限 5000 条（多选共享该上限，超限显示 `+`）
- 退回 `window.find()` 的旧环境不支持范围与匹配选项

## 卸载

```sh
dsh plugin --profile <profile> remove dsh-find-bar
```
